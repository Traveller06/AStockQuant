# AStockQuant v7.3 核验报告

核验日期：2026-09-11

## 结论

v7.3 已恢复并默认启用用户确认的规则1，同时加入严格300只样本逐阶段门禁、冻结缓存验证、统一数据截止日、实时进程显示和完整运行清单导出。实现依据见[设计说明](docs/superpowers/specs/2026-09-11-v7-3-entry-and-sample-integrity-design.md)，核心实现见[main.py](main.py)，离线回归见[test_execution.py](test_execution.py)。

## 已验证内容

- 规则1在无放量时生成“买入观察”，同日放量升级为“强确认”。
- 规则2只接受同日放量。
- 规则3只在两个条件均已发生后触发，不读取后续交易日。
- 组合撮合继续使用下一交易日开盘，交易明细记录入场规则和确认等级。
- 严格门禁接受完全一致的300只唯一代码，并拒绝299只、重复代码或与准备样本不一致的输入。
- 每日资金账增加现金和持仓数量；双引擎曲线增加股票现金和股票持仓数量。
- Python 语法编译通过，19项离线回归测试全部通过。

验证命令：

```text
python -m py_compile main.py test_execution.py
python test_execution.py
```

测试结果：`Ran 19 tests ... OK`。

## 仍需 Windows 本机核验

当前执行环境未安装 PySide6、pyqtgraph 和 requests，因此没有把“窗口可以在 Windows 打开”或“在线数据源可用”写成已验证结论。安装后应按[升级安装说明](升级安装_v7.3.txt)运行窗口，并用用户已经准备的300只缓存执行一次严格验证。只有界面最终显示“输入代码300 / 准备样本300 / 缓存载入300 / 信号成功300 / 质量审计300”，该次运行才算完整。

## 研究边界

年化2%—5%、亏损年度不低于-1%仍是研究验收目标，不是收益承诺。若历史资格或滚动验证未通过，软件会继续标记为未达标；v7.3 不连接真实券商，也不会自动交易。
