# 周线趋势确认：本地股票池筛选

用户目标：在中文 Windows 软件中一键按照既有周线趋势确认策略寻找股票，保留现有回测、尾盘和其他旧策略。

1. 仅扫描 `cache` 中六位股票代码的日线 CSV，读取 `a_share_universe.json` 的简称（若存在）；不自动下载、不修改原数据。界面必须显示实际扫描数量和数据截止日，不把部分缓存称作全市场。
2. 当前交易日 15:30 前不读取当天未完成的日线；截止日前最新日期落后的股票列为“行情过期”。周一至周四只使用此前完整周线，避免把部分周量当作已完成周量。
3. 从未激活状态重放既有周线策略最近形态有效期，依次显示“当日确认”“等待确认”，其余为未通过、过期或数据错误。确认信号只是下一交易日的研究意图，不执行真实订单。
4. 保存最近一次筛选到独立 `v8_runs/screens/latest_screen.json`，支持打开上次结果与 CSV 导出；旧缓存和账户目录不更改。
5. 旧缓存固定为前复权，入口 `qfq` 显式映射内核 `forward`。不允许把现有缓存错标为后复权或不复权。缺少真实成交额与交易状态的数据仍提示其限制。

验收：真实形态由未激活进入等待确认，逐日测试确认只在条件完成日出现；追加未来行情不改变历史结果；周一量能不会计入前一完整周；Qt 页面能够在后台扫描线程中显示可选择的股票和规则；旧版回归与新安装包独立解压验证通过。
