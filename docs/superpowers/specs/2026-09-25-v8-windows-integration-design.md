# AStockQuant v8.0 Windows 双击版集成设计

日期：2026-09-25
状态：用户已于 2026-09-25 书面审核通过
基线安装包：`AStockQuant_v7_6_3_空分钟缓存修复_双击版.zip`
开发分支：`codex/v8-phase1`

## 1. 目标

把已经模块化开发的 v8.0 内核安全接入现有 Windows 中文桌面量化系统，在不破坏 v7.6.3 原策略、缓存、模拟持仓和双击启动方式的前提下，新增可选的“周线趋势确认”研究、回测和模拟能力。

本次交付必须是完整闭环，不发布只显示信号但缺少撮合、账户或审计结果的半成品。

## 2. 范围

### 2.1 必须包含

- 完成现有周线趋势确认计划的 Task 9–11：
  - A股下一交易日撮合与 T+1 约束；
  - 停牌、涨跌停、费用、滑点、整手和资金约束；
  - 回测引擎、运行清单、逐笔审计和结果持久化；
  - v7.6.3 基线一致性、因果性和最终验证。
- 保留 v7.6.3 全部页面和策略。
- 新增独立的“周线趋势确认”页面，默认不启用新策略。
- 支持研究、历史回测和本地模拟，不连接真实账户。
- 生成新的 Windows 双击安装 ZIP。

### 2.2 不包含

- 国泰海通或其他券商真实下单。
- 自动交易授权、账户密码或交易终端自动化。
- 用新策略替换旧默认策略。
- 修改旧行情缓存、尾盘策略缓存或模拟持仓文件格式。
- 删除或覆盖用户已有数据。

## 3. 总体架构

现有 v7.6.3 继续作为 Windows 桌面壳和旧策略兼容层；v8.0 作为独立 Python 包随安装包发布。

```text
Windows 中文桌面界面
├── v7.6.3 原有页面与策略
├── 尾盘两日短线
└── 周线趋势确认（新增、手动选择）
        ↓
桌面应用适配层
        ↓
v8 策略注册表 / 回测服务 / 运行审计
        ↓
数据适配器 / 撮合器 / 组合账本 / 状态存储
```

桌面端不得直接复制 v8 策略算法。界面只负责参数收集、任务启动、进度显示和结果展示；交易规则只存在于 v8 模块中。

## 4. 兼容策略

- 原 `main.py`、`tail_strategy.py` 和旧测试继续保留。
- 原菜单顺序不变，在尾盘模块之后新增“周线趋势确认”。
- `legacy_v7` 保持默认策略；`weekly_trend_confirmation` 必须由用户主动选择。
- 旧 `cache`、`tail_strategy_cache`、`tail_strategy_state.json`、样本和验证快照只读取或复用，不迁移、不改写。
- v8 新状态和结果保存到独立目录，例如 `v8_state` 与 `v8_runs`。
- 安装升级只替换程序文件；用户数据目录不包含在发布 ZIP 中。

## 5. 数据适配

桌面适配层把旧版 pandas 行情转换为标准 `Bar`：

- 时间必须带 `Asia/Shanghai` 时区；
- 代码、OHLC、成交量、成交额和来源字段完整；
- 同一股票时间唯一且严格递增；
- 复权口径显式传递，不允许混用；
- 交易日历由数据日期生成并允许后续替换为正式交易所日历；
- 转换失败只跳过对应股票并写入中文错误记录，不中断整批任务。

适配器不得反向修改旧 DataFrame 或旧缓存文件。

## 6. 新页面

“周线趋势确认”页面至少包含：

- 策略说明和版本号；
- 数据范围、复权口径、初始资金和费用参数；
- 运行回测、打开上次结果、导出审计包；
- 当前进度、错误数量和数据截止日；
- 收益、回撤、交易次数、胜率、盈亏因子和仓位；
- 逐笔信号、订单、成交、未成交原因和中文规则检查；
- 明确提示“研究/模拟用途，不连接真实券商”。

页面不得提供真实下单按钮。

## 7. 撮合与账户规则

- 收盘后信号只能在下一交易日尝试成交。
- A股买入数量必须为 100 股整数倍。
- 买入当日不可卖出；T+1 后才允许退出。
- 停牌或涨停导致入场取消，不追价重试。
- 停牌或跌停导致退出保持待卖并顺延。
- 现金不得为负，持仓和费用必须与逐笔成交对账。
- 佣金、印花税和滑点都写入运行清单。

## 8. 状态与审计

每次运行生成独立 `run_id`，并保存：

- 策略版本、参数版本和应用版本；
- 数据截止日、样本哈希和数据哈希；
- 信号、订单、成交及其关联 ID；
- 每条规则的实际值、阈值、是否通过和中文说明；
- 未成交、到期、失效、取消和数据错误；
- 资金曲线、持仓快照、年度指标和最终摘要。

保存必须采用原子写入；文件损坏、版本不兼容或截止日倒退时拒绝静默加载。

## 9. 故障隔离

- v8 模块导入失败时，新页面显示中文错误，但旧页面仍可打开。
- 单只股票错误不得终止整批回测。
- 账户账本、配置或运行清单损坏时终止当前 v8 运行，避免输出不可核对结果。
- 网络失败不得删除已有缓存。
- 所有用户可见异常必须包含阶段、股票或任务范围及建议操作。

## 10. 测试与验收

交付前必须同时通过：

1. v8 全量单元测试和集成测试；
2. v7.6.3 原有 `test_execution.py` 与 `test_tail_strategy.py`；
3. 信号日与成交日分离、T+1、停牌和涨跌停测试；
4. 现金、费用、持仓、权益和逐笔成交对账；
5. 未来数据追加不改变历史信号和决定；
6. v7 基线结果与升级前一致；
7. 无 PySide6 环境下的界面构造契约测试；
8. ZIP 根目录启动器、依赖文件和版本号检查；
9. 从最终 ZIP 重新解压并再次运行全部离线测试；
10. 发布包不得包含账户、缓存、持仓、运行结果或个人数据。

- 中文升级说明；
