# v8.3.6 全市场历史行情恢复检查点

目标：保留策略和旧缓存，在全市场扫描中恢复被不可衔接缓存阻塞的股票。

证据：用户验收有135条前复权无法对齐、20条重叠不足、5条非正价格、4条数据源过期/连接问题。公开文档不包含个人CSV、股票持仓、行情或账户数据。

原因：旧缓存与增量数据在请求新数据之前合并；旧合并失败直接终止。即使数据源能返回完整独立历史，也会再次强制与旧缓存合并。

设计：保留严格merge_history。先验证现有历史；若格式损坏、价格异常、复权衔接失败，重新请求独立历史。验证通过后在v8_history_snapshots/按代码保存不可变CSV及校验元数据；不写旧cache或旧增量文件。短历史仍需21个完整周，不足时单独报告。新数据过期、非正值、缺列、重复日期、非有限值等继续失败，不虚构成功。
