下次恢复时按以下顺序只读检查：

1. 打开本文件确认当前任务。
2. 查看两个计划专属账本的最后一条记录。
3. 运行 `git status --short --branch` 和 `git log -10 --oneline`。
4. 已有 `Task N: complete` 记录的任务不得重做。
5. 从第一个没有完成记录的任务继续。
6. 每个任务通过测试后立即提交，并更新本文件及GitHub恢复分支。

不得通过重新初始化项目、复制旧版本目录、`git reset --hard` 或 `git checkout --` 恢复任务。
