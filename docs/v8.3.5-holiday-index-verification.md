# v8.3.5 休市日期与新浪编码解析修复（2026-10-04）

## 已确认问题

用户v8.3.4截图在10月4日报错：腾讯仅到9月30日，程序要求10月2日；新浪指数解析报 Extra data。旧默认日期只跳过周末，因此错误要求国庆休市日。新浪历史响应第一段字符串后还有赋值，整体 json.loads 把后续代码也当成JSON。

## 已完成

- 依照上交所2026年度公告补齐元旦、春节、清明、劳动、端午、中秋、国庆休市区间。默认日期仍采用上海时区和15:30完成门槛；调休周末保持休市。10月4日默认9月30日，10月8日15:30前仍默认9月30日。
- 通用历史 TradingCalendar 与策略参数不改；公布休市表当前覆盖2026年，其他年份保留原工作日回退，2027年需要新增官方日历。
- 新浪股票/指数编码统一读取第一个赋值字符串，安全忽略分号后附加脚本。拒绝HTML、非字符串、空编码及表达式拼接；不执行提供方返回代码。可信本地解码器及前复权处理保持原逻辑。
- 旧股票缓存、全市场名册、模拟账户不改写，不重建项目。
